# 🏧 ATM Management System Using Python

## 📌 Project Overview

The **ATM Management System** is a beginner-friendly Python project that simulates basic ATM operations. It allows users to authenticate themselves using their PIN and password and perform different banking operations through an interactive menu.

This project demonstrates the practical implementation of Python concepts such as dictionaries, functions, loops, conditional statements, exception handling, and built-in modules.

## ✨ Features

- 🔐 **User Authentication:** Login using account PIN and password.
- 💰 **Check Balance:** View the current account balance.
- 💵 **Deposit Money:** Add money to the account.
- 🏧 **Withdraw Money:** Withdraw money with balance validation.
- 👤 **Account Information:** View account details with masked Aadhaar and mobile numbers.
- ⚠️ **Input Validation:** Handle invalid inputs and incorrect amounts.
- 🔄 **Interactive ATM Menu:** Perform multiple operations until choosing Exit.
